# Artist Daily Practice｜艺术实践日报

一套为艺术家与独立创作者设计的、媒介无关的 Markdown 日常记录模板。

艺术实践不只包括完成的作品，也包括实验、失败、材料观察、排练、研究、判断变化、准备、维护与恢复。这套模板用于保留作品如何形成，而不是把艺术生活变成效率仪表盘。

## 如何开始

- [`templates/five-minute-log.md`](templates/five-minute-log.md)：五分钟低负担记录。
- [`templates/full-practice-review.md`](templates/full-practice-review.md)：完整记录实验、判断、困难和项目状态。
- [`examples/filled-example.md`](examples/filled-example.md)：虚构填写示例。

所有文件都是普通 Markdown，可以复制到 Obsidian、其他笔记软件或任意文件夹中，无需安装插件。

## 设计原则

- 先记录实际发生的事，再作解释。
- 区分直接观察与个人理解。
- 不把完成作品视为唯一的进展。
- 保留有价值的失败、不确定、暂停和判断变化。
- 不强迫普通的一天产生洞见或意义。
- 只填写有用的部分，可以删除空白章节。
